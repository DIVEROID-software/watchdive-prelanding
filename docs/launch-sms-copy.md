# WatchDive 출시 SMS — 검토용

정본: `src/lib/launchSms/copy.ts`. 9개 언어 × 일반 신청자 / $3 예약자 = 18종.

- 일반 신청자: Kickstarter 오픈, 선착순 100명 $149, 이후 $200, 공개 출시 링크.
- 예약자: 보장받은 $149 최저가와 전용 구매 링크. 재결제 유도나 선착순 경쟁 문구 없음.
- 저장된 가입 언어를 사용하며, 없거나 지원하지 않는 값은 영어로 표시.
- 프리다이빙·스쿠버 경로와 무관하게 같은 출시 가격 안내를 사용.
- 한국어 또는 가입 국가 KR 검토본은 `(광고)`와 무료수신거부 표시를 유지. 버디 참여 **현황** 메일 제목과 구분.

## 발송 연결에 필요한 것

문구와 검토 화면만 준비했습니다. SMS 발송 업체·발신번호·스케줄러를 설치하거나 실제 문자를 보내지 않았습니다.

`{launchUrl}`는 공개 Kickstarter 링크, `{reservationUrl}`는 예약자 전용 구매 링크입니다. `{senderContact}`와 `{optOut}`는 실제 등록된 연락처 및 수신거부 수단으로 운영 연결 시 치환합니다. URL·발신번호·무료수신거부 번호를 임의로 만들지 않았습니다.

운영 발송 시에는 별도의 명시적 SMS 동의, 현재 수신거부 상태, 실제 수신번호 국가와 허용 발송 시간, 제공업체의 발신자·수신거부 지원을 확인해야 합니다. 이메일 인증이나 측정 동의를 SMS 동의로 대신하지 않습니다. 측정 동의 철회 자체를 SMS 수신거부로 간주하지 않습니다.

문자 길이는 링크 치환과 인코딩에 따라 달라집니다. 검토 화면의 글자 수는 템플릿 문자 수이며 실제 SMS 과금 단위가 아닙니다. 예약자 링크 발급과 수신자 판정은 이 문구 모듈에서 구현하지 않았습니다.
